## Featured project

### [DataCube](https://github.com/nonamilua/datacube)

A responsive web application I built for **speedcubing practice and statistical analysis**. It lets users time and organize solves, track their history, compare cubes and tags, and explore interactive statistics across different events.

The project combines a browser-based analytical interface with a persistent backend and includes account-based data storage, import/export workflows, data visualization, authentication-related controls, database migrations, automated tests, and multilingual support.

**Stack:** TypeScript · Vite · Bootstrap · Chart.js · FastAPI · SQLModel · Alembic · SQLite
